# Policies Directory

This directory contains policy documents and rules for Lamoni Rose Hill Cemetery.

## Files

- **BenchPolicy.html** - Guidelines for installing and maintaining benches
- **DecorationRules.html** - Rules and guidelines for decorations
- **LotOwnerAndUseRules.html** - Rules for lot owners and usage
- **MultipleCremains.html** - Policy for multiple cremains
- **1901-Rules.html** - Historical rules from 1901 (replaced by new rules)
- **AnswersToQuestions.html** - Frequently asked questions and answers
- **bylaws.html** - Cemetery bylaws and governance

## Editing Policies

Policy content can be edited by:

1. Editing the corresponding text file in `editable-content/policies/`
2. Running: `python scripts/update-html-from-text.py`
3. The HTML file will be automatically updated

## PDF Versions

Some policies also have PDF versions available in this directory.
